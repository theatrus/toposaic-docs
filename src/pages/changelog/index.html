Release notes

What changed, version by version.

Every build for Windows, macOS, and Linux is on the GitHub releases page. The desktop app checks for a newer version on launch and can install it in place.

Current · 28 July 2026

Version 0.6.1

One fix: printed pieces no longer wear a grey outline around every edge.

The terrain color bleeds over a piece's edge

A piece's side wall is a cut through the terrain, and it printed in the rock color from the base right up to the rim. Seen from anything but straight above, that drew a grey outline around every piece — worst on hills, where the wall is tallest and faces you.

The top of the wall now carries the land cover from the surface directly above, so the color runs over the rim and around the tabs instead of stopping dead at the top edge. Below the band the cut face is still rock, because a cut through a hill is rock.

Edge color bleed on the Surface tab sets how deep the band runs, from 0 to 2 mm, starting at 0.4 mm — two layers at the usual 0.2 mm layer height. Set it to a whole number of the layers you slice at, so the band ends on a layer boundary rather than part way through one. Zero turns it off and gives back the plain rock wall.

28 July 2026

Version 0.6.0

Filament slots you can actually load, two new things to put on a map, and a way to save a whole job in one step.

Ferry crossings

Mapped ferry routes draw as their own layer, in a deep teal of their own or folded in with the roads, alongside railways and aerial lifts. Like the others, a ferry costs a filament only where the map really has a crossing — an inland map never spends one. See choosing what the map draws.

Markers and labels

Place building highlights, color dots, blank flags, and named flags by latitude and longitude. Named flags emboss their text in a bundled font, with the banner width, height, and text size under your control. Manual surface labels follow the terrain; raised plaques give text a flat backing. Each label has its own print size and map rotation.

Only the filaments you print

A 3MF now carries a color for each feature the model really contains and nothing more. Two layers set to one color share a slot, a layer the map has none of costs nothing, and every slot names a real filament preset instead of leaving the slicer to guess. The Colors tab shows which filament number each layer prints from and reorders them to match the spools already loaded. See the color printing guide.

Save a whole job at once

Write a job's print files, or its STLs, to a folder in one step — with toposaic-setup.json, the setup that made them, alongside. Saved setups now offer to store changes when the model drifts from them, and keep their last five versions to roll back to. See saving setups and files.

Also in this release

  • Each setup saves a stable puzzle seed and signed tile coordinates, so a later super-tile run can still make edges that match tiles you already printed. Outer edge notches are now optional, and off by default.
  • Turn the map by any bearing, and pan it without moving the selected ground.
  • Buildings keep their proportions as the view closes in, rather than growing taller than the terrain.
  • The base label reads at the precision its map can support — or can be left off entirely.

Earlier

Version 0.5.0

  • Mount a full terrain tile or display base with printable straight pins, angled pins, or a flush French-cleat receiver, with matching wall hardware, screw clearance, and alignment spacers.
  • Use linked map zoom to resize the selected ground area, or switch to map-only zoom while keeping the model span fixed.
  • Scan the rebuilt Surface tab by terrain, water, roads and bridges, railways and lifts, or imported trails.
  • Scale roads and railways from mapped OpenStreetMap widths where available, with class minimums and a maximum you set.
  • Open color 3MF output as separated pieces in Bambu Studio and OrcaSlicer.

Version 0.4.1

  • Repair isolated bad elevation samples before interpolation, so one stray reading cannot spike the terrain or break the mesh around it.
  • Open update notes in the system browser from the desktop app.

Version 0.4.0

  • Save named model setups and move them between machines as JSON. Inspect or clear each map cache from the settings pane.
  • Import GPX and KML routes as their own colored trail layer. Railways and aerial lifts get separate controls, colors, heights, and line history.
  • Choose project, painted, or geometry-only 3MF output to suit Bambu Studio, OrcaSlicer, and other tools.
  • High and Ultra detail generation use less time and memory, and generated previews replace the draft view when a job finishes.
  • Mesh, tray, building, overlay, and export code reject bad input without crashing, and models pass stricter watertightness checks before release.

Older versions

Notes for 0.3 and earlier are on the GitHub releases page, which also carries every downloadable build.
